# Coverage additions after independent review

1. Add a TCP public test with two listener addresses and eight simultaneously live accepted roots from eight distinct client identities. Fail exactly one listener close, physically releasing its fixture socket before publishing the failed promise. The same close must close every listener/root, retain the original error, terminate the owned group and every captured thread, and preserve shared workers. The old product must fail group termination.
2. Add a QUIC public test with four outbound connections created by one client transport using direct public dial calls to one real isolated server. These are the QuicChannels actually registered in the client's channels collection. Fail exactly one outbound QuicChannel close, releasing it physically first. Closing that client must retain the exact failure, close all four QuicChannels and their UDP parents, terminate its owned group and every captured thread, and leave the server group alive. The old product must fail group termination.
3. Run the two new tests with the fix reverted and then fixed; preserve native XML. No product implementation change is planned without a failing behavior test. Commit the added tests separately only after red/green.

Why outbound QUIC: accepted server QuicChannels are not directly entered in QuicTransport.channels; the listening UDP parent is. The review's literal accepted-child test does not target that collection path. Outbound connections do.

Invariants: every listener/root in a captured close set settles before owned group shutdown; one failed close cannot skip cleanup of other captured entries; failed promise identity stays immutable; group/thread death is asserted before finally cleanup; TCP shared workers and the unrelated QUIC server remain usable. Cleanup fixtures release resources on failures but never satisfy assertions on behalf of the product. No existing-main test changes, JVM tuning flags, reflection, mocks, weakened assertions or timeout increases.
