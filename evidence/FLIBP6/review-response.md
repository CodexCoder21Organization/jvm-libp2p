# Root review response

The exact Netty 4.2.10.Final group source uses one termination promise; its child-termination listener completes that promise only with success, and shutdownGracefully returns it. Both owned groups in this patch use that concrete implementation and fixed valid quiet-period/timeout values. Thus the proposed simultaneous ordinary channel error plus failed group-termination future is not a reachable dependency failure in the requested path. Deliberately altering the foreign group's own promise or a process-level failure is a different input; no new aggregate or mutation of an already-published channel error is justified by that hypothetical. AR-H2 is withdrawn, rather than patched without a real reproducer.

Sources read: [MultithreadEventExecutorGroup](https://github.com/netty/netty/blob/netty-4.2.10.Final/common/src/main/java/io/netty/util/concurrent/MultithreadEventExecutorGroup.java), particularly its termination listener and shutdownGracefully, and [NioIoHandler](https://github.com/netty/netty/blob/netty-4.2.10.Final/transport/src/main/java/io/netty/channel/nio/NioIoHandler.java), whose prepareToDestroy closes registered handles. The latter reaches the channel's native close through [AbstractNioChannel](https://github.com/netty/netty/blob/netty-4.2.10.Final/transport/src/main/java/io/netty/channel/nio/AbstractNioChannel.java).

AR-H1 describes unchanged QUIC admission/snapshot code and remains an untested concurrency hypothesis. Missing a channel in a snapshot alone is not proof of an open resource after owned group termination, because Netty also closes registered handles during group shutdown. No product change is being guessed from that static risk; no test result is claimed for concurrent QUIC registration here.

The two concrete coverage gaps are addressed by the plan in coverage-plan.md. The QUIC test targets outbound QuicChannels, since those are the connection channels this implementation actually registers; accepted connections are children of its registered UDP listener. The added tests must go red with the cleanup fix removed before they can support publication.
