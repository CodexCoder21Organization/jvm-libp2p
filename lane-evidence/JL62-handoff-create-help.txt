usage: handoff-cli create --title <title> [options]
     --depends-on <value>    Dependency handoff URL; repeatable.
     --file <value>          Markdown body file; content is used verbatim.
     --help                  Show command usage.
     --json                  Emit machine-readable JSON.
     --list <value>          Target priority-list URL.
     --state-dir <value>     Use embedded state in this local directory.
     --summary <value>       One-paragraph summary.
     --title <value>         Handoff title (required).
     --url <value>           Remote service URL (default url://handoff/).
