usage: artifact-publisher
CLI tool for copying a Maven artifact directory into a Maven repository.
 -a,--artifact-dir <arg>       Path to a pre-built artifact directory
                               containing JAR and POM files. Use this to
                               publish without rebuilding.
    --api-url <arg>            HTTP API URL for artifact upload (e.g.,
                               https://api.kotlin.directory/upload). Use
                               instead of --maven-repository for
                               HTTP-based publishing.
 -b,--buildrule <arg>          Build rule that produces the Maven artifact
                               directory. Required for publish mode.
    --force                    Skip confirmation step and install
                               immediately
 -h,--help                     Print this help message
    --identity <arg>           Private key for SSH authentication
 -l,--list-artifacts           List all artifacts in the repository with
                               their latest versions
                               (group:artifact:version format)
    --maven-repository <arg>   Root of the target Maven repository (SSH
                               format: user@host:path, or local path)
    --port <arg>               SSH port for remote repository (default 22)
    --verbose                  Enable verbose SSH logging
 -w,--workspace <arg>          Path(s) to workspace roots. Path separators
                               permitted. Required for publish mode.
